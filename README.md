# Vkontente — прототипы интерфейса

Кликабельные HTML-прототипы нового UI/UX сервиса автоматизации редакции. Целевой экран — десктоп 1920×1080.

| Экран | Файл |
|---|---|
| Справочники → Этапы: интерактивная карта этапов | [stages.html](stages.html) |

[hig-audit.md](hig-audit.md) — аудит интерфейса по Apple HIG и правила для новых экранов.

Прототипы работают на демо-данных и не связаны с рабочим сервисом. Кнопка «Сохранить» запоминает карту только в вашем браузере.

## Запуск локально

```bash
python3 -m http.server 5173
```

Затем откройте http://127.0.0.1:5173/stages.html
